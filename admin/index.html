Ajuda & políticas

Este painel é um arquivo único que funciona offline. Os dados ficam no cache do navegador e, se as chaves de Firebase/Firestore ou Apps Script estiverem preenchidas em Configurações, também na nuvem.

  • Termos de Serviço — uso interno da equipe Callango Nerd.
  • Privacidade — nenhum dado sai do navegador sem chaves configuradas.
  • Política de conteúdo — não publique conteúdo ilegal ou de terceiros sem crédito.

Repositório oficial

Conecta o painel ao repositório callangonerd-dev/callangonerd. O painel grava os JSON de publicação direto no repositório e o GitHub Pages serve o site público.

O token fica apenas no cache local deste navegador.

Publicar no repositório

Gera e commita site-config.json, posts.json, sitemap.xml e feed.xml na pasta de dados do repositório.

—

Importar acervo histórico do repositório

Lê os arquivos da pasta /backup (feed.atom e XML de backup do Blogger) e importa as postagens como rascunhos.
